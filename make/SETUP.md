# בניית התרחיש ב-Make - מדריך צעד אחר צעד

שני תרחישים:
- **תרחיש א' - תזכורת:** כל מוצאי שבת מגיע מייל עם קישור לטופס. (2 מודולים, 5 דקות)
- **תרחיש ב' - הסוכנת:** ממלאים טופס ומקבלים במייל קישור למסמך עם כל הרצף. (כ-9 מודולים, 40-60 דקות)

כדאי לבנות קודם את ב' ולבדוק אותו, ורק אחר כך את א'.

---

## שלב 0 - מה צריך לפני שמתחילים

| מה | איפה | הערה |
|---|---|---|
| חשבון Make | make.com | התוכנית החינמית מספיקה (1,000 פעולות בחודש, וריצה אחת היא כ-10 פעולות) |
| חשבון Google | - | ל-Forms, Sheets, Docs ו-Gmail |
| **מפתח API של Claude** | console.anthropic.com → API Keys | צריך להטעין קרדיט (מינימום כמה דולרים). ריצה אחת עולה סנטים. **את המפתח מדביקים רק ב-Make, לא בצ'אט, לא בריפו ולא בשום קובץ** |
| הקובץ `system-prompt.md` | בתיקייה הזו | ההוראות לסוכנת. מדביקים אותו ב-Make |

---

## שלב 1 - הטופס (Google Forms)

יוצרים טופס חדש בשם **"בוחרות באומץ - נושא השבוע"** עם 3 שאלות:

| # | שאלה | סוג | חובה |
|---|---|---|---|
| 1 | נושא השבוע | תשובה קצרה | כן |
| 2 | רגע אמיתי (משפט-שניים. אפשר להשאיר ריק ולקבל שאלות שיעזרו למצוא סיפור) | פסקה | לא |
| 3 | אירוע או מבצע להזמנה (אם יש) | פסקה | לא |

**טיפ:** שמרי את הקישור לטופס במסך הבית של הטלפון.

---

## שלב 2 - גיליון הארכיון (Google Sheets)

יוצרים גיליון בשם **"בוחרות באומץ - ארכיון"**. בשורה 1 כותבים את הכותרות:

| A | B | C | D | E |
|---|---|---|---|---|
| תאריך | נושא | רגע אמיתי | קישור למסמך | הרצף המלא |

זה הזיכרון האפיזודי של הסוכנת: בכל ריצה היא קוראת ממנו את 3 השבועות האחרונים.

> אם כבר יש לך שבוע שנכתב ב-Claude Code (למשל "גבולות בזוגיות"), אפשר להדביק אותו ידנית כשורה ראשונה. כך כבר בריצה הראשונה יהיה לה ממה ללמוד.

---

## שלב 3 - תרחיש ב': הסוכנת

ב-Make: **Create a new scenario**. בונים לפי הסדר:

```
[1 Forms] → [2 Sheets: 3 שבועות] → [3 Text aggregator] → [Router]
                                                         ├─ אין רגע → [4 Claude: שאלות] → [5 Gmail: שאלות]
                                                         └─ יש רגע  → [6 Claude: רצף] → [7 Docs] → [8 Sheets: שורה] → [9 Gmail: קישור]
```

### מודול 1 - Google Forms: Watch Responses
- מתחברים לחשבון Google ובוחרים את הטופס.
- **Limit:** 1.
- כשנשאלים מאיפה להתחיל, בוחרים **From now on**.

### מודול 2 - Google Sheets: Search Rows (Advanced)
- בוחרים את גיליון הארכיון.
- **Query:**
  ```
  select B, E order by A desc limit 3
  ```
  כלומר: הנושא והרצף המלא של 3 השבועות האחרונים, מהחדש לישן.

> אם המודול "Advanced" לא מסתדר, אפשר להשתמש ב-**Search Rows** רגיל עם **Maximum number of returned rows = 3**. השאירי את סדר המיון על השורות האחרונות, אם האפשרות מופיעה. בדקי בריצת הבדיקה שאכן חוזרים השבועות האחרונים ולא הראשונים.

### מודול 3 - Text aggregator
- **Source module:** מודול 2.
- **Text:**
  ```
  שבוע: {{2.B}}
  {{2.E}}
  ---
  ```
  (את `{{2.B}}` ו-`{{2.E}}` לא מקלידים. לוחצים בשדה ובוחרים מהרשימה של מודול 2 את העמודות "נושא" ו"הרצף המלא".)
- כך 3 השבועות נהיים טקסט אחד שאפשר לשלוח ל-Claude.

> בריצה הראשונה, כשהגיליון ריק, המודול לא יחזיר כלום וזה תקין. כדי שהתרחיש לא ייעצר, פתחי את ההגדרות המתקדמות של מודול 2 ובדקי שהמודול ממשיך גם כשאין תוצאות. בגרסאות מסוימות של Make צריך להוסיף שורת דמה ראשונה לגיליון.

### Router - שני מסלולים
מוסיפים **Router** אחרי מודול 3. לכל מסלול מגדירים **Filter** (לוחצים על הקו):

| מסלול | שם הפילטר | תנאי |
|---|---|---|
| עליון | אין רגע | `רגע אמיתי` (ממודול 1) → **Does not exist** |
| תחתון | יש רגע | `רגע אמיתי` (ממודול 1) → **Exists** |

### מודול 4 (מסלול "אין רגע") - Anthropic Claude
- **Connection:** Add → מדביקים את מפתח ה-API. **זה המקום היחיד שבו המפתח נמצא.**
- **Model:** `claude-sonnet-5-5`. אם הוא לא ברשימה, בוחרים את הגרסה הכי חדשה של Sonnet, או מקלידים ידנית.
- **Max tokens:** 2000.
- **System prompt:** מדביקים את **כל** התוכן של `system-prompt.md`.
  > אם אין שדה System, מדביקים את ההוראות בתחילת ההודעה, ומתחתיהן את הטקסט של ההודעה.
- **Message (role: user):**
  ```
  מצב: שאלות סיפור

  נושא השבוע: {{1.נושא השבוע}}
  ```

### מודול 5 - Gmail: Send an email
- **To:** הכתובת שלך בלבד.
- **Subject:** `בוחרות באומץ - שאלות לסיפור על {{1.נושא השבוע}}`
- **Content:** התשובה של Claude ממודול 4 (בדרך כלל השדה נקרא `Text` או `Content`), ומתחתיה הקישור לטופס.

### מודול 6 (מסלול "יש רגע") - Anthropic Claude
- אותו Connection ואותו System prompt כמו במודול 4.
- **Max tokens:** 8000. בעברית הרצף המלא ארוך, ופחות מזה עלול לחתוך את הסוף.
- **Message (role: user):**
  ```
  מצב: רצף מלא

  נושא השבוע: {{1.נושא השבוע}}

  רגע אמיתי: {{1.רגע אמיתי}}

  אירוע להזמנה: {{1.אירוע או מבצע להזמנה}}

  שבועות קודמים (לא לחזור על פתיחה, שאלת סקר, סיפור או CTA):
  {{3.text}}
  ```

### מודול 7 - Google Docs: Create a Document
- **Name:** `בוחרות באומץ - {{formatDate(now; "DD.MM.YYYY")}} - {{1.נושא השבוע}}`
- **Content:** התשובה של Claude ממודול 6.
- **Folder:** מומלץ לפתוח תיקייה ייעודית בדרייב.

### מודול 8 - Google Sheets: Add a Row
- גיליון הארכיון. ממלאים:

| עמודה | ערך |
|---|---|
| תאריך | `{{formatDate(now; "YYYY-MM-DD")}}` |
| נושא | `{{1.נושא השבוע}}` |
| רגע אמיתי | `{{1.רגע אמיתי}}` |
| קישור למסמך | הקישור למסמך ממודול 7 (בדרך כלל `Document ID`, ואז כותבים לפניו `https://docs.google.com/document/d/`) |
| הרצף המלא | התשובה של Claude ממודול 6 |

### מודול 9 - Gmail: Send an email
- **To:** הכתובת שלך בלבד.
- **Subject:** `בוחרות באומץ - הרצף לשבוע: {{1.נושא השבוע}}`
- **Content:**
  ```
  הרצף מוכן:
  https://docs.google.com/document/d/{{7.Document ID}}

  לפני פרסום - לעבור על "לבדוק לפני פרסום" בסוף המסמך.
  ```

### טיפול בשגיאות (מומלץ)
- לחיצה ימנית על מודול 6 → **Add error handler** → **Resume** או **Break** עם ניסיון חוזר אחד.
- אפשר להוסיף אחריו Gmail עם ההודעה "הרצף לא נוצר השבוע - אפשר להריץ ב-Claude Code".

## שלב 4 - בדיקה (חזרה גנרלית)

1. לוחצים **Run once** בתחתית המסך.
2. ממלאים את הטופס **בלי** רגע אמיתי. אמור להגיע מייל עם שאלות.
3. לוחצים שוב **Run once**, וממלאים את הטופס **עם** רגע אמיתי.
4. בודקים:
   - [ ] נוצר מסמך בדרייב, ויש בו מפה, 7 תכנים ו"לבדוק לפני פרסום"
   - [ ] הטקסט לא נחתך באמצע (אם נחתך, מעלים את Max tokens)
   - [ ] אין `#` או `**` במסמך
   - [ ] נוספה שורה לגיליון
   - [ ] הגיע מייל עם קישור
   - [ ] הקול נשמע כמוך, ואין ביטויים אסורים
5. לוחצים על הבועה שמעל כל מודול כדי לראות מה נכנס ומה יצא. זה ה"לוג" של Make.
6. רק אחרי שהכל עובד: מפעילים את התרחיש (**ON**).

## שלב 5 - תרחיש א': תזכורת שבועית

תרחיש חדש:
1. **Schedule:** Every week → Saturday → 21:00 (אזור זמן: Asia/Jerusalem. בחורף כדאי לבדוק שהשעה מתאימה לצאת השבת).
2. **Gmail: Send an email** אלייך:
   - Subject: `מה הנושא של "בוחרות באומץ" השבוע?`
   - Content: `הטופס: <קישור לטופס>`

## כשמשנים את הקול או המבנה

ההוראות נשמרות במקור אחד: קבצי הסוכנת בריפו. אחרי כל שינוי ב-`voice.md`, `structure.md`, `profile.md` או `SKILL.md`:

```bash
bash make/build-prompt.sh
```

ואז מדביקים מחדש את `system-prompt.md` במודולים 4 ו-6. (הקובץ נבנה מקומית ולא עולה לריפו, כי הוא כולל את תוכן הקורס.)

## מה Make לא עושה (ולכן Claude Code נשאר הדרך העיקרית)
- אין שיחה: אי אפשר לבקש תיקון ("תקצרי את הסיפור"). מתקנים ב-Doc, או מריצים ב-Claude Code.
- "למדנו בדרך" לא מתעדכן אוטומטית. הערות סגנון מוסיפים ב-Claude Code.
